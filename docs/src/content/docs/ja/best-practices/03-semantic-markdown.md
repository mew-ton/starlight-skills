---
title: セマンティックな Markdown
---

AIエージェントはドキュメントの「生のテキストデータ」を読み取ります。指示を正確にパースさせるためには、構造化されたセマンティック（意味論的）な Markdown を記述する必要があります。

優れたスキルは簡潔で、構造化されており、パースが容易です。見出し（`##`）、箇条書き（`-`）、番号付きリスト（`1.`）を積極的に活用し、複雑なワークフローを論理的なステップバイステップの手順に分解してください。

深いネスト（階層）や、過度に複雑な内部リンクは避けてください。エージェントに対して、深くネストされた Markdown セクション間を何度も往復するように指示すると、コンテキストを見失う可能性が高くなります。

長い文章で手順を説明する代わりに、決定的な**チェックリストパターン**を使用してください。チェックリストはエージェントを複雑な操作フローに沿って明示的に誘導し、検証のスキップやルールの無視を防ぐのに効果的です。
