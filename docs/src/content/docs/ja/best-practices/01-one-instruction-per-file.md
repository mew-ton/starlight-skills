---
title: 1タスク1ファイル
---

スキルを作成する際は、1つのファイルのスコープを特定の指示やコンテキストに限定し、複数の無関係なルールを1つの巨大なドキュメントにまとめないでください。

1つのファイルに複数の情報を詰め込みすぎると、人間の読者が必要な情報を探しづらくなるだけでなく、AIエージェントにとっても「現在ユーザーが意図しているタスクに対してどのルールを適用すべきか」の判断が非常に困難になります。

例えば、「フロントエンドのルーティング規則」と「データベースのマイグレーション規則」を1つの `development-rules.md` に統合してはいけません。必ず `frontend-routing.md` と `db-migrations.md` のように分離してください。
