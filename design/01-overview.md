# Overview

## プロダクト概要

starlight-skills は Astro Starlight 向けのプラグインである。
ドキュメントサイトの著者が、ドキュメントページと **AI エージェントがインストール可能なスキル** を一元管理できるようにすることを目的とする。

「スキル」とは Agent Skills 仕様に準拠した配布単位を指す。スキルは `npx skills add` などの標準ツールによってインストールされ、AI エージェントの能力を拡張する。

## ユースケース

このプラグインは性格の異なる 2 つのユースケースを想定する。

### UC-1: ドキュメントをスキルとして転写する

人間向けに書かれたドキュメントを、そのままスキルとして配布したい場合。

- ページの読者は **人間が主体** であり、AI はその内容を手順・ルール・知識として利用する
- ページの構成はドキュメントの慣習に従う（説明・例示・背景・根拠を含む）
- 著者はドキュメントを書くことだけに集中し、スキルへの転写はプラグインが担う

**具体例:** デザインシステムやデザインパターンのドキュメント

UC-1 においてドキュメントとスキルを別ページに分けるのは、ドキュメントが **画像や MDC コンポーネント** を含む場合など、人間向けの表現がそのままスキル本文として適さないケースに限られる。そうでない場合（プレーンな Markdown で完結するドキュメント）は、同一ページでスキルを兼ねることがメンテナンス性の観点で望ましい。

### UC-2: スキルをドキュメントとして公開する

AI 向けに書かれたスキルを、人間にも読ませたい場合。

- ページの内容は **AI への指示が主体** であり、人間はその内容を規約・ルールとして参照する
- ページの構成はスキルの慣習に従う（簡潔・命令的・箇条書き中心）
- 著者はスキルを書くことだけに集中し、ドキュメントサイトへの掲載はプラグインが担う

**具体例:** コーディングガイドラインを業務委託向けルールとして提示する

---

どちらのユースケースでも、1 つのページが **ドキュメントとスキルの両方として** 機能する。著者がページを 2 箇所に管理する必要はない。

## アクター

| アクター | 説明 |
|---|---|
| ドキュメント著者 | プラグインを設定し、スキルページを書く人 |
| 人間の読者 | サイト上でドキュメントまたはルールを参照する人（業務委託・チームメンバー等） |
| スキル利用者 | 標準ツール（`npx skills add` 等）でスキルをインストールする人またはエージェント |

## 責務

### コア

`src/content` 配下の Markdown ファイルのうち、フロントマターに `skill: true` を持つものをスキルとして認識する。これがプラグインの唯一のコア責務であり、以下の機能はすべてこの認識結果に基づく。

### 機能

| # | 機能 | 必須 |
|---|---|---|
| F-1 | ドキュメントサイトにスキルカタログページを動的に生成する | デフォルト有効 |
| F-2 | ドキュメントサイトにスキルページを動的に生成する | デフォルト有効 |
| F-3 | ビルド成果物またはリポジトリルートにスキルファイル群を出力する | ◎ |

F-2 はオプションである。スキルページ（`skill: true` の md）は著者が通常のドキュメントページとして管理するため、プラグインが自動生成しなくてもよい場面がある。

F-3 の出力先は `dist/.well-known/skills/`（デプロイ後に URL から発見可能）とリポジトリルートの `skills/`（デプロイ不要で参照可能）の 2 種類があり、独立して有効化できる。

## 非目標

- ホスティングや CDN の設定
- スキルのバージョン管理
- 認証・アクセス制御
- スキルのテスト実行
