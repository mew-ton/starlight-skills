# サイト統合

## ページの種類

このプラグインが扱うページは 2 種類あり、明確に区別する。

| 種類 | 説明 |
|---|---|
| **元ページ** | 著者が `skill: true` を付けて執筆した Starlight ドキュメントページ |
| **スキルページ** | プラグインが生成する、AI スキルとしての見え方を示すページ |

スキルページは元ページとは **別の URL に生成される独立したページ** である。元ページの内容をそのまま表示するのではなく、AI スキルとして配布される形式（フロントマターの `description` 等のメタ情報 + 本文）で構成される。

元ページは Starlight が通常のドキュメントページとして管理する。元ページへのナビゲーション（サイドバーへの掲載等）は著者が Starlight の設定で制御する。

プラグインが生成するすべてのページ（カタログ・スキルページ・付随ファイル閲覧ページ）には `noindex` メタタグを付与し、検索エンジンのインデックス対象から除外する。

---

## URL 構造

プラグインが生成するすべてのページは、設定可能なベースパス（デフォルト: `__skills`）配下に配置される。

| ページ | URL |
|---|---|
| カタログ | `/<skillsRoot>/` |
| スキルページ | `/<skillsRoot>/<skill-name>` |
| 付随ファイル閲覧ページ | `/<skillsRoot>/<skill-name>/<subfile-relative-path>` |

`skillsRoot` はプラグインオプションで変更できる（詳細は `05-configuration.md` 参照）。

`skillsRoot` に指定したパスと同名のページが著者のコンテンツ内に存在する場合はビルドエラーとする。

## カタログページ

`autoGeneratePages.catalog` が有効な場合に生成される（デフォルト: 有効）。

### ビジュアルコンセプト

**linter のルール一覧**に近い見え方を想定する。スキルを一覧で素早くスキャンでき、各スキルへ辿れる構成。

- ルール名（= スキル名）が視覚的に目立つ
- 各エントリはコンパクトで、一覧性を優先する
- カテゴリでまとまりを把握できる

### 表示内容

スキルが存在する場合、カテゴリごとにセクションを分けてスキルを一覧表示する。各スキルには以下の情報を表示する:

| 情報 | 内容 |
|---|---|
| スキル名 | スキル名（リンク付き）。コード表記で表示する |
| 説明 | `description` フィールドの内容 |

階層カテゴリ（例: `development/frontend`）の表示方法は `catalogCategoryDisplay` オプションで制御できる。デフォルトはネスト表示（`development` セクションの下に `frontend` をネスト）。未分類のスキルは独立したセクションとしてまとめる。スキルが 1 つも存在しない場合は、スキルの追加方法を示す案内を表示する。

### リンク先の決定

| `autoGeneratePages.skill` | リンク先 |
|---|---|
| 有効 | スキルページ（`/<skillsRoot>/<skill-name>`） |
| 無効 | 元ページ |

### インストールコマンドの表示

スキル利用者向けに、スキルのインストールコマンド（`npx skills add <repository>`）をページ内に表示する。

## スキルページ

`autoGeneratePages.skill` が有効な場合に生成される（デフォルト: 有効）。

### 目的

元ページは人間向けに書かれている（UC-1・UC-2 どちらでも）。スキルページはその内容を AI スキルの観点で整理・提示するページであり、**AI スキルが実際にどのような情報を持つかを人間が確認できる** ことを目的とする。

### ビジュアルコンセプト

**linter のルールドキュメント**に近い見え方を想定する。スキル名・説明・本文が明確に区別されて読める構成。

### 表示内容

| 情報 | 出力対象 |
|---|---|
| スキル名 | フロントマターの `skill-name`（または `title` から導出） |
| 説明 | フロントマターの `description` |
| 本文 | ページの本文（Starlight 固有のフロントマターは除外） |
| メタ情報 | `skill-license`・`skill-compatibility`・`skill-allowed-tools`・`skill-metadata`（設定された場合） |
| 付随ファイル一覧 | `subfiles` に宣言されたファイルの一覧。各ファイルは閲覧ページへのリンクとして表示する。`subfiles` が空の場合はこのセクションを表示しない |

---

## 付随ファイルの閲覧ページ生成

`autoGeneratePages.skill` が有効な場合にのみ生成される。スキルページが生成されない場合、`subfiles` はビルド出力へのファイルコピーにのみ使用され、サイト上の閲覧ページは生成されない。

付随ファイルの閲覧ページはサイドバーに表示しない。

### 表示ルール

| ファイル種別 | 表示方法 |
|---|---|
| Markdown / MDX | ドキュメントページとして通常レンダリング |
| それ以外（スクリプト・設定ファイル等） | ファイル内容をコードブロックとして表示 |

---

## サイドバー

スキルが 1 つ以上存在する場合、Starlight のサイドバーにスキル専用グループが追加される。スキルがない場合はグループ自体を追加しない。

グループ内の構成:

- カテゴリが存在する場合、カテゴリは **折りたたみ可能なサブメニュー** として Skills グループ配下に表示される
- 各スキルはそのカテゴリのサブメニュー内に並ぶ
- 未分類のスキルは Skills グループ直下に並ぶ（サブメニューなし）
- リンク先は `autoGeneratePages.skill` が有効な場合はスキルページ、無効な場合は元ページ

グループのラベルはプラグインオプション（`sidebarLabel`）で設定できる。
